to go back through chat logs**.

**About dates:** dates come from the session log, which records time in UTC. Work done in the
evening in Tampa can show up as the next day.

**About numbers:** these notes are a **history**, so some older numbers appear on purpose, marked
as outdated. The **current** numbers are in `WHAT_I_DID.md` and `REPORT.md`, which are checked
against the data automatically. These notes are not.
